# ถ่ายโอน รพ.สต. สู่ท้องถิ่น

แดชบอร์ดติดตามการถ่ายโอน รพ.สต. สอน. และ สสช. ไปยังองค์การบริหารส่วนจังหวัด (อบจ.) และเทศบาล/อบต. เทียบกับการใช้บริการสิทธิหลักประกันสุขภาพแห่งชาติ (UC) และเงินที่ สปสช. โอนตรงถึงหน่วยบริการ ดูได้ตั้งแต่ระดับประเทศจนถึงรายหน่วย (9,878 หน่วยบริการ 76 จังหวัด)

- **แหล่งข้อมูล:** สถาบันวิจัยระบบสาธารณสุข (สวรส.) ชุดข้อมูลดิบวันที่ 11 ก.ย. 2569
- **วิเคราะห์และสร้างโดย:** พลเทพ วิจิตรคุณากร คณะแพทยศาสตร์ มหาวิทยาลัยสงขลานครินทร์

> โลโก้ สวรส. และ HPRC เป็นของหน่วยงานเจ้าของ ใช้เพื่อระบุแหล่งข้อมูลและผู้จัดทำเท่านั้น ไม่รวมอยู่ในสิทธิ์การนำโค้ดไปใช้ต่อ

## มุมมองในแดชบอร์ด

| แท็บ | เนื้อหา |
|---|---|
| ภาพรวมการถ่ายโอน | จำนวนหน่วยแยกรุ่นปีงบที่ถ่ายโอน (≤2565–2570) สังกัดปัจจุบัน บุคลากรที่ถ่ายโอน และตารางสัดส่วนการถ่ายโอนรายภาค เขต จังหวัด อำเภอ หรือหน่วยรับถ่ายโอน |
| ก่อน–หลังถ่ายโอน | เปรียบเทียบ OP/PP ต่อหัวของรุ่นที่ถ่ายโอนปีงบ 2566–2568 ก่อนและหลังถ่ายโอน เทียบกับกลุ่มไม่ถ่ายโอนหรือกลุ่มกำหนดถ่ายโอน 2570 (difference-in-differences เชิงพรรณนา) มีกราฟรายรุ่น กราฟผลต่างตามปีเทียบกับปีถ่ายโอน (event study) และตารางสรุป |
| การใช้บริการ OP/PP | แนวโน้ม OP/PP ต่อหัวประชากร UC ปีงบ 2563–2569 แยกรุ่นถ่ายโอน เลือก Send/Adj และค่าต่อหัว/ยอดรวม พร้อมตารางหน่วยที่ไม่มีข้อมูล |
| เงินโอน สปสช. | เงินโอนตรงถึงหน่วย ปีงบ 2566–2569 เป็นบาทต่อหัวหรือล้านบาท แยกรุ่นและกลุ่มกองทุน |
| ค้นหารายหน่วย | ค้นจากชื่อ รหัส 5 หลัก อำเภอ หรือจังหวัด แล้วดูข้อมูลพื้นฐาน บุคลากร OP/PP 7 ปี และเงินโอนรายกองทุน |

ตัวกรองด้านบน (ภาค เขต สปสช. จังหวัด อำเภอ รุ่นถ่ายโอน สังกัด ขนาดหน่วย) ใช้ร่วมกันทุกแท็บ

## เปิดดูในเครื่อง

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (หรือใช้คำสั่งด้านล่าง)
2. ไปที่ **Settings → Pages** เลือก **Deploy from a branch** → branch `main` → โฟลเดอร์ `/ (root)` → **Save**
3. รอประมาณ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/pcu-transfer-dashboard/`

```bash
cd pcu-transfer-dashboard
git init
git add .
git commit -m "แดชบอร์ดถ่ายโอน รพ.สต."
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/pcu-transfer-dashboard.git
git push -u origin main
```

> **ก่อนเผยแพร่:** `data/data.js` มีข้อมูลรายหน่วยบริการ (ประชากร UC, OP/PP, เงินโอน, จำนวนบุคลากร) ถ้า repo เป็น public ทุกคนจะเข้าถึงได้ ควรตรวจสอบเงื่อนไขการใช้ข้อมูลกับ สวรส. ก่อน หรือตั้ง repo เป็น private (GitHub Pages ของ repo private ต้องใช้แพ็กเกจที่รองรับ)

## อัปเดตข้อมูล

เมื่อได้ไฟล์ดิบชุดใหม่ (ชื่อไฟล์และคอลัมน์เหมือนเดิม) ให้สร้าง `data/data.js` ใหม่:

```bash
pip install pandas openpyxl
python scripts/build_data.py --input "path/to/00 Raw data ถ่ายโอน สวรส"
```

ไฟล์ดิบที่ต้องมีในโฟลเดอร์:

| ไฟล์ | sheet | เนื้อหา |
|---|---|---|
| `EXP_PCU01_ถ่ายโอน.xlsx` | PCU | ข้อมูลหลักรายหน่วย สถานะ/ปีถ่ายโอน สังกัด บุคลากร |
| `EXP_PCU02_UC_OPPP.xlsx` | UC_OPPP | ประชากร UC, OP/PP (Send/Adj) รายปี ปีงบ 2563–2569 |
| `EXP_PCU03_BUDGET.xlsx` | PCU_BUDGET | เงินโอน สปสช. รายกองทุน ปีงบ 2566–2569 |

## การเตรียมข้อมูลและวิธีคำนวณ

- รหัสหน่วยบริการ (`PCU_CODE`) แปลงเป็นข้อความ 5 หลักก่อนเชื่อมไฟล์ (มีรหัสพิเศษ `6304X`)
- สถานะและรุ่นถ่ายโอนใช้จาก `EXP_PCU01` ทุกมุมมอง (ไฟล์ OP/PP ระบุต่างไป 20 หน่วยในอุดรธานี)
- ตัด 53 แถวในไฟล์ OP/PP ที่ไม่มีรหัสหน่วย และรวมแถวซ้ำ (43955 รพ.สต.เนินเสรี) ด้วยค่าสูงสุด
- ขนาดหน่วยค่า "K" และ "on" จัดเป็น "ไม่ระบุ"
- กลุ่มกองทุน: OP = กองทุนผู้ป่วยนอก (1), PP = กองทุนสร้างเสริมสุขภาพฯ (3), งบลงทุน/ค่าเสื่อม (6), แพทย์แผนไทย (18), นอกระบบ UC = สวัสดิการรักษาพยาบาลพนักงานส่วนท้องถิ่น (60) และผู้ประกันตนคนพิการ (61), ที่เหลือเป็น "อื่นๆ ในระบบ UC"
- **ต่อหัว (OP/PP)** = ผลรวมบริการ ÷ ประชากร UC ของหน่วยที่มีข้อมูลในปีนั้น
- **เงินโอนต่อหัว** = ผลรวมเงินโอน ÷ ประชากร UC ของทุกหน่วยในกลุ่ม

## วิธีเปรียบเทียบก่อน–หลังถ่ายโอน

- ปีถ่ายโอน T = ปีงบแรกที่หน่วยอยู่สังกัดใหม่ (เช่น รุ่น 2566 ถ่ายโอน 1 ต.ค. 2565) ช่วงก่อน = ปีงบ 2563 ถึง T−1 ช่วงหลัง = T ถึง 2568 (เลือกรวม 2569 ได้)
- ค่าแต่ละปี = ผลรวมบริการ ÷ ประชากร UC ของกลุ่ม ค่าช่วง = ค่าเฉลี่ยของปีในช่วงนั้น
- ผลต่าง (DiD) = (หลัง − ก่อน ของรุ่นที่ถ่ายโอน) − (หลัง − ก่อน ของกลุ่มเปรียบเทียบในช่วงปีเดียวกัน)
- กราฟ event study = (รุ่นที่ถ่ายโอน − กลุ่มเปรียบเทียบ) ในแต่ละปี ปรับให้ปี T−1 = 0
- ค่าเริ่มต้นใช้เฉพาะหน่วยที่มีข้อมูลครบทุกปี (balanced panel) และใช้ตัวกรองพื้นที่และขนาดหน่วยเท่านั้น
- ตัวชี้วัด: OP/PP (Adj/Send) ต่อหัว และสัดส่วน PP ต่อ OP (Adj)
- **ตรวจข้อมูลก่อนตีความ:** ดัชนีประชากร UC (ปีงบ 2563 = 100), ร้อยละหน่วยที่ไม่มีข้อมูล และอัตราส่วน Adj ÷ Send แยกรุ่นกับกลุ่มเปรียบเทียบ ใช้ทุกหน่วยในพื้นที่ที่เลือก
- **ผลต่างแยกตามลักษณะหน่วย:** บุคลากรที่ถ่ายโอน ขนาดหน่วย สังกัดใหม่ (เทียบกับกลุ่มเปรียบเทียบทั้งหมด) และภาค ประเภทหน่วย (เทียบกับกลุ่มเปรียบเทียบในกลุ่มเดียวกัน) รวมหลายรุ่นโดยถ่วงน้ำหนักตามจำนวนหน่วย
- เป็นการวิเคราะห์เชิงพรรณนา ยังไม่ปรับปัจจัยอื่นและยังไม่ทดสอบนัยสำคัญ

## ข้อควรระวังในการตีความ

- ปีงบ 2569 ยังไม่ครบปี ค่า Send ต่ำกว่าปีอื่นมาก และค่า Adj อาจเป็นค่าคาดการณ์ทั้งปี
- นิยาม Send/Adj รอยืนยันจากเจ้าของข้อมูล
- เงินโอนเป็นเงินที่ สปสช. **โอนตรงถึงหน่วยบริการ** เท่านั้น หน่วยที่ยังไม่ถ่ายโอนส่วนใหญ่รับเงินผ่าน CUP จึงใช้เทียบทรัพยากรรวมระหว่างกลุ่มไม่ได้
- มี 16 หน่วยที่เป็น CUP เอง ได้เงิน OP เหมาจ่ายเต็มจำนวน
- ข้อมูลบุคลากรมีเฉพาะหน่วยที่ถ่ายโอนแล้ว ใช้ได้ครบสำหรับรุ่นปีงบ 2566–2568
- ปีงบ 2570 เป็นรายการที่มีกำหนดถ่ายโอน (เริ่ม 1 ต.ค. 2569)
